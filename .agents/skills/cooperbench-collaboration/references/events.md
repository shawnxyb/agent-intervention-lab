# 上报口径

沿用同一 issue_id 跟踪同一问题，字段格式见 report_event 工具定义。evidence 写具体路径、符号、diff 或真实公开测试结果；attempts 记录实际局部修复及结果，无尝试为 []。

| kind | 何时使用 |
|---|---|
| status | 普通进展、局部失败或完成 |
| contract_change | 有证据表明公共接口/契约变化影响同伴功能；仅同文件修改或猜测不算 |
| cross_task_blocker | 有明确证据的跨职责阻塞可直接上报；普通自身功能错误先自查 |

resolved 是 Worker 的判断：当前代码与实际验证支持问题解决时，沿用原标识和类型填 true；仅 ACK、补丁变化或合并成功不能证明功能问题解决。控制器只附加来源、时间和快照，不背书该判断。合并冲突由控制器对稳定快照探测，不由 Worker 上报。
